Icons
=====

The inslopnia eye-and-sun mark replaces the Kanboard "KB" icon:

- `logo.svg`: the mark on a transparent background (ink #141414)
- `adaptive-favicon.svg`: the mark with embedded CSS, the eye turns light when the OS prefers a dark theme
- `favicon.png`, `touch-icon-*.png`, `/favicon.ico`: rendered from the mark

Original Kanboard sources, kept for reference:

- `inkscape-text-icon.svg`: Original Inkscape file
- `inkscape-path-icon.svg`: Inkscape file with the text converted to path (Inkscape: `Path -> Object to Path`)
- `inkscape-optimized-icon.svg`: Inkscape export striped of unecessary elements (Inkscape: `Save as -> Save as Optimized SVG`)
